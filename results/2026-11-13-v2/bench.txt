# IMPORTANT: values are QEMU emulation artefacts.

# Results are useful for comparing driver versions on the same host,
# NOT for predicting real PCI hardware performance.
#
# IRQ latency = wall-clock time from write(N) to result available via read()
# DMA latency = wall-clock time for EDU_IOC_DMA_ROUNDTRIP (4096 bytes, full)
